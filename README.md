# E-Commerce Sales Analysis & Power BI Dashboard

## Project Overview

This project analyzes an e-commerce sales dataset using **MySQL and Microsoft Power BI**.

The project started with SQL-based business analysis and was then extended into an interactive Power BI dashboard to visualize important sales and customer insights.

# DAX Measures Used

## Total Revenue

```DAX
Total Revenue = SUM(sales[total_amount])
```

Calculates the total revenue generated from all orders.

---

## Total Orders

```DAX
Total Orders = COUNT(sales[order_id])
```

Calculates the total number of orders.

---

## Average Order Value

```DAX
Average Order Value = DIVIDE([Total Revenue], [Total Orders])
```

Calculates the average revenue generated per order.

---

## Return Rate %

```DAX
Return Rate % = DIVIDE(
    CALCULATE(
        COUNT(sales[order_id]),
        sales[returned] = "Yes"
    ),
    [Total Orders]
)
```

Calculates the percentage of orders that were returned.

---

## Average Customer Spend

```DAX
Avg Customer Spend =
AVERAGEX(
    ALL(sales[customer_id]),
    CALCULATE([Total Revenue])
)
```

Calculates the average spending per customer.

---

## Above Average Customer

```DAX
Above Avg Customer =
IF(
    [Total Revenue] > [Avg Customer Spend],
    1,
    0
)
```

Identifies customers whose spending is above the average customer spending.

# Key Insights

- Electronics generated the highest revenue among the categories.
- South and North were the highest-revenue regions.
- Male and Female customers contributed a similar share of total revenue.
- The overall return rate was approximately **5.52%**.
- The dashboard highlights the highest-revenue customers and products.
- Monthly revenue trends show changes in sales performance over time.
